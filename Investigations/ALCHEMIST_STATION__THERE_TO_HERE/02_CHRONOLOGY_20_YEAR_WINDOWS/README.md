# Chronology — 20-year windows

**Start:** 200 BCE. **Initial formation segment:** 200 BCE–400 CE. Extend in consecutive 20-year windows after the formation segment where the record permits.

## Period segmentation

- 200–1 BCE: ten consecutive windows (200–181, 180–161, ..., 20–1 BCE).
- 1–200 CE: ten consecutive windows (1–20, 21–40, ..., 181–200 CE).
- 201–400 CE: ten consecutive windows (201–220, 221–240, ..., 381–400 CE).
- Then 401–420 CE onward, continuing without changing the interval width.

No year zero. Dates given only to a century or a broad range must **not** be silently narrowed to one window.

Use [WINDOW_TEMPLATE.md](WINDOW_TEMPLATE.md) for each researched interval; create interval files as evidence is gathered. Each window must carry *conditions / perception / station / lineage / texts / transition / sources / uncertainty*.

## Initial checkpoints (NOT fully sourced deposits)

Candidate investigations include Pseudo-Democritus and the early Greek alchemical treatises (broadly first century CE); traditions associated with Maria the Jewess (poorly dated); Zosimos around 300 CE; the Leiden and Stockholm technical papyri around 300 CE; subsequent Greek, Arabic, and Latin reception. Each anchor requires independent source validation and a dated evidence record before assignment to a specific 20-year window.
